# 本地乐谱来源与署名

默认32份 MuseScore MSCX 乐谱来自 DCMLab 的公开古典钢琴语料库，使用各仓库 `reviewed/` 中的校对版文件。各文件地址、固定 Git 提交、SHA-256 和许可见同目录的 `catalog.json`。

- Robert Schumann, *Kinderszenen*, Op. 15 (13 pieces): [DCMLab/schumann_kinderszenen](https://github.com/DCMLab/schumann_kinderszenen)
- Claude Debussy, *Suite bergamasque* (4 pieces): [DCMLab/debussy_suite_bergamasque](https://github.com/DCMLab/debussy_suite_bergamasque)
- Pyotr Ilyich Tchaikovsky, *The Seasons*, Op. 37a (January, April, October): [DCMLab/tchaikovsky_seasons](https://github.com/DCMLab/tchaikovsky_seasons)
- Edvard Grieg, selected *Lyric Pieces*: [DCMLab/grieg_lyric_pieces](https://github.com/DCMLab/grieg_lyric_pieces)
- Wolfgang Amadeus Mozart, selected piano sonata movements: [DCMLab/mozart_piano_sonatas](https://github.com/DCMLab/mozart_piano_sonatas)
- Franz Liszt, selected *Years of Pilgrimage* pieces: [DCMLab/liszt_pelerinage](https://github.com/DCMLab/liszt_pelerinage)

DCMLab 语料文件采用 Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0)。公开展示这些乐谱时应署名 DCMLab 和对应曲集，并链接本归属说明及许可；改编内容须遵循相同许可。许可正文随每个曲集资源保存。
