# 25. 闹钟 (设置 → 闹钟, 1.0.359)

[← 返回目录](../../MECHANICS.md)

设置里多了一页 **闹钟** (在 沟通 后面; 电脑 `alarm.py` + `pages/alarm_ui.py`, 手机 `core/Alarm.kt` + `ui/AlarmScreen.kt`)。这一页的设置**即时保存、没有等待期、没有"保存本页修改"**, 只存在本机 (`alarm_config.json` 加密 / 手机 `alarm.json`), **不随设备同步**: 哪台设备响由各自的开关决定。

### 25.1 本机的闹钟

- **开启 (每天重复)**、**时间** (时:分)、**铃声**、**音量**。
- 铃声: 经典警报 (和违反合约的警报同一个音) / 三音提示 (整点提示音) / 柔和钟声 (沟通主动消息的提示音) / 电脑上"自选文件"(wav, mp3, m4a, aac, wma) / 手机上"系统铃声"(系统的铃声选择器, 没选 = 系统默认闹钟铃声) / 手机上"自选文件"(1.0.402: 从文件里选一个音频, 复制进应用私有目录 `alarm_sound_*`, 不超过 25 MB 且系统能读出音频才算数; 换文件时删掉旧的副本; 文件没了 / 放不出来 → 回到经典警报; 只存本机, 不同步)。有 **▶ 试听** 按钮 (最多放 6 秒; 闹钟正在响时不能试听)。
- 音量 0 - 100: 铃声的幅度, 增益 = (音量/100)² (50 听起来约一半); 电脑上不动系统音量; 手机响的时候把系统"闹钟音量"拉到最大 (实际大小由这里的音量决定), 关掉后恢复。
- 响铃 = 循环播放直到用户关掉, 最长 5 分钟 (没人关就自己停, 弹窗还在)。电脑: 置顶的"⏰ 闹钟"弹窗 (点"关闭闹钟"), 盖在所有页面 (包括睡眠的遮罩) 上面; 手机: 只能手动关闭的提示窗 (带系统通知, 通知上也有"关闭闹钟"按钮, 通知用全屏意图点亮屏幕), 黑雾也不遮它。**睡眠中、合约中、任何页面都照响**。
- 判断 (`Alarm.check`, 每秒一次): 预定时刻 `nxt` = 上一次响过 / 开启 (改时间) 之后的下一个钟点; `nxt` 到了且没超过 **15 分钟** (`MISS_SECONDS`) 就响, 超过了 (电脑睡着 / 程序没开 / 手机关机) 这次不响、直接排下一次; 响过的记下 (`fired`) 不再响。开启 / 改时间 / 开关共时闹钟 (换对象) 都会重新计时, 之前已经过去的钟点不补响。
- 手机: 下一次响铃的时刻交给系统闹钟 (`AlarmManager.setAlarmClock`, 熄屏 / 打盹 / 后台都准点; 没有精确闹钟权限时退回 `setAndAllowWhileIdle`, 设置页会提示"允许精确闹钟"), 到点 `AlarmReceiver` 推进一次 Core, 由 `Core.alarmTick` 开始响。电脑关机 / 睡眠时当然不会响。

### 25.2 共时闹钟 (沟通 → ⏰)

- 聊天框上方的 **⏰ / ⏲** 按钮 (⏰ = 现在这个对象就是共时闹钟) 打开"共时闹钟"窗口: 一个开关"把『对象』设为共时闹钟", 打开后下面列出**响铃的设备** (本机 + 绑定的设备, 手动勾选; 默认只勾本机; 关掉之后选择也留着, 再打开沿用)。**一次只有一个对象是共时闹钟**, 打开别的会替换它。
- 开着、并且**本机在响铃设备里**时: 本机的闹钟不再用自己的时间, 而是**跟随这个对象日程里的实际起床时间** (`Comm.co_alarm_fn` / `coAlarmFn`); 铃声和音量仍用本机"设置 → 闹钟"里的, 开关不用开。本机不在名单里的设备照常用自己的闹钟。设置页的闹钟页会写明"共时闹钟已开启 …, 上面的开关和时间现在不生效", 以及下一次的时间。
- 实际起床时间 (`Comm.wake_after` / `wakeAfter`): 有日程文件 (24.11) 的对象 = 每天的起床时刻 `routine.wake_at` (初始起点 + 睡眠结束时间波动, 就是睡眠段的结束; `routine.wake_times` / `Routine.wakeTimes`), 同一天任何设备算出来都一样, 所以各设备不用互相通知; 旧式固定钟点日程的对象 = 睡眠段的结束钟点; 两者都没有 = 没有起床时间, 不会响 (窗口里提示)。
- 设置 (`cfg["alarm_co"]` = {pid, devs: 响铃设备的 id, ts}) 随设备同步 (沟通文档键 `alarm`, 后改的为准; 关闭也同步)。
- 内置 Claudia 的**睡眠结束时间波动由 [-20,10] 改成 [-5,0]**: 起床时刻总在 6:25 - 6:30。旧的内置日程文件当时进了升级链: 没改过的会自动换成新的; 用户自己改过的不动 (1.0.372 起升级链清空重新开始)。
