# 11. 界面

[← 返回目录](../../MECHANICS.md)

- 窗口基准尺寸 1280 × 860, 最小 980 × 680, 按屏幕 DPI × 界面字号缩放, 不超过主屏幕可用区域 (去掉任务栏) 的 96%; 程序刚打开时放在主屏幕正中.
  窗口**可以最大化** (标题栏的最大化按钮 / 双击标题栏), 也可以拖边缘改大小; 按 **F11** 全屏 / 退出全屏 (全屏时没有标题栏); 换主题 / 语言重建界面时不改窗口的大小和位置.
- 切换语言 / 字号 / 主题会重建整个界面, 期间显示带进度条的加载页. 启动时也有同样的加载页.
- 切换页面时先停在上一页, 新页面在后面画完后一次性换上, 避免分块渲染 (Windows 8 及以上).
- 桌面与 Android 侧边栏的模块与分隔线均可拖动排序（Android 端长按后拖动）；分隔线以下未选中的入口淡化显示。顺序和分隔线位置保存在本机 `ui_prefs.json`，跟随界面主题即时重绘，不参与设备同步。
- 桌面侧边栏新增知识库入口。知识库以本地 Obsidian Markdown Vault 为正文来源，包含技巧库、概念库和待审提案；探索 / 保守模式、思路参考、学科和排除技巧设置与 Vault 路径保存在 `.oit_kb/config.json`。技巧卡有“通用”“解释后通用”“不通用”三种通用性：解题子代理先判断题型，再筛选能直接用于书写过程的卡片；开启思路参考时，不通用卡只能提供方向或检查角度，过程仍需用其他方法独立推导。默认探索模式允许解题使用有证明的库外技巧并提交审核提案；保守模式禁止库外二级结论。概念笔记不进入解题检索。
- 知识库的导入笔记支持手动选文件或文件夹，也支持“自动生成”：用户选择文件夹和图像、txt、md、json、Anki `.apkg` 类型后，程序递归扫描并把明显配套的文本与图片一起交给 AI；重复内容跳过，概念卡直接保存，技巧卡进入待审提案。
- PC 与 Android 设置 → 额外功能均提供 Obsidian 打开和官网下载入口；桌面支持手动选择 Obsidian 程序安装目录及默认安装路径自动识别，显示当前路径；Android 未安装时从打开入口转到官方下载页。桌面「订阅 CLI」显示 Antigravity CLI，并说明与普通桌面客户端的区别。
- 各页面不显示说明性的小字 (用法提示, 规则解释); 只保留实时状态和数值 (剩余时间, 当前值, 待生效的修改, 拦截次数等), 以及作者写的风味文本.
- 「都市之意」主题在左侧导航最上面多一个 **指令 (Prescript)** 页 (第 22 节); 其他主题没有这一页. 切换到这一主题时弹一次标题为「都市之意」的提示窗.
- 本文里作者写的风味文本显示在界面上, 左边带一道细竖线:
  - 1.1 设置冷静期的理念: 设置 → 基本设置的最下方;
  - 4.1 默认放行的原因: Rules 页模式卡片下方;
  - 6.2 休息越学越多: Timer 页下方的空白处, 一直显示;
  - 6.5 "不要勉强.": 连点领取休息时间后的提示末尾;
  - 9 重置: Reset 页重置按钮下方.
