# 11. 界面

[← 返回目录](../../MECHANICS.md)

- 窗口基准尺寸 1280 × 860, 最小 980 × 680, 按屏幕 DPI × 界面字号缩放, 不超过主屏幕可用区域 (去掉任务栏) 的 96%; 程序刚打开时放在主屏幕正中.
  窗口**可以最大化** (标题栏的最大化按钮 / 双击标题栏), 也可以拖边缘改大小; 按 **F11** 全屏 / 退出全屏 (全屏时没有标题栏); 换主题 / 语言重建界面时不改窗口的大小和位置.
- 切换语言 / 字号 / 主题会重建整个界面, 期间显示带进度条的加载页. 启动时也有同样的加载页.
- 切换页面时先停在上一页, 新页面在后面画完后一次性换上, 避免分块渲染 (Windows 8 及以上).
- 各页面不显示说明性的小字 (用法提示, 规则解释); 只保留实时状态和数值 (剩余时间, 当前值, 待生效的修改, 拦截次数等), 以及作者写的风味文本.
- 「都市之意」主题在左侧导航最上面多一个 **指令 (Prescript)** 页 (第 22 节); 其他主题没有这一页. 切换到这一主题时弹一次标题为「都市之意」的提示窗.
- 本文里作者写的风味文本显示在界面上, 左边带一道细竖线:
  - 1.1 设置冷静期的理念: 设置 → 基本设置的最下方;
  - 4.1 默认放行的原因: Rules 页模式卡片下方;
  - 6.2 休息越学越多: Timer 页下方的空白处, 一直显示;
  - 6.5 "不要勉强.": 连点领取休息时间后的提示末尾;
  - 9 重置: Reset 页重置按钮下方.
