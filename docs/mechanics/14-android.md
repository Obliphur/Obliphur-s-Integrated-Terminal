# 14. Android 版 (`Android version/`)

[← 返回目录](../../MECHANICS.md)

Android 版按本文第 1 ~ 11 节实现, 数值和规则都相同. 下面只写 Android 上做法不同或做不到的地方.

### 14.1 平台

- Kotlin + Jetpack Compose, Android 10 (API 29) 及以上.
- 数据目录是应用私有目录 (`files/data/`), 文件名和第 10 节相同. 卸载应用时系统会一起删除.
- 一个前台服务每秒推进一次 (联网计时, 休息倒计时, 每 5 秒的检查, 整点, 零点). 通知栏常驻一条运行状态.
- 设备睡眠时用闹钟在下一个要处理的时刻叫醒 (联网时间到, 冷静期结束, 休息结束, "还在吗", 整点, 设置到期).
  需要在 设置 → 整点记录 里允许精确闹钟, 否则系统可能推迟几分钟. 每次启动 (VPN 权限问完之后) 还没解除电池优化时会申请一次, 设置 → 基本设置 里也可以解除.
- 开机后自动启动并接管网络.

### 14.2 断网方式 (VpnService)

手机上的两种断网方式都是代理 (本地 VPN), 不经过任何服务器: **代理-全屏蔽 (Proxy block-all)** 对应电脑上的 Adapter, **代理 - 规则过滤** 对应 Proxy. 需要允许 OIT 建立 VPN 连接; 权限被撤销 (例如打开了别的 VPN 应用) 时页面顶部显示红条, 并发一条通知.

| 断网方式 | 状态 | VPN 做什么 |
| --- | --- | --- |
| **代理-全屏蔽 (Proxy block-all)** (设置值 Adapter) | 离线 | 接管 DNS, 所有域名一律拦截 (回 NXDOMAIN, 不看网站名单); 局域网不受影响 (设备同步要用) |
| | 联网中 | 只接管 DNS, 全部放行 |
| **代理 - 规则过滤** (设置值 Proxy) · 黑名单 | 联网中 | 只接管 DNS, 全部放行 |
| | 离线, 网站黑名单为空 | 只接管 DNS, 全部放行 |
| | 离线, 网站黑名单不为空 | 接管 DNS: 黑名单里的网站一律拦截 |
| **Proxy** · 白名单 | 联网中 | 只接管 DNS, 全部放行 |
| | 离线, 网站白名单为空 | 全部流量进 VPN 后丢弃 (局域网地址除外, 设备同步要用; Android 13 起, 当前 Wi-Fi / 有线网络的网段不是 10 / 172.16 / 192.168 开头时 (校园网, 100.64 …) 也排除, 网段比 /16 大的不排除) |
| | 离线, 网站白名单不为空 | 全部流量进 VPN: DNS 只放行白名单里的网站, 其余转发; 加密 DNS / QUIC 一律丢掉 (见下) |

- VPN **只看网站名单**: 判定顺序同 4.2, 但两种名单模式下应用名单都不参与联网判定 —— 应用名单只用来**锁定应用** (14.6).
  (以前按 VPN 的应用路由和 DNS 查询的发起者禁用名单里的应用, 很多应用照样能用: 有缓存, 或者绕过 DNS.)
- 应用写**包名** (如 `tv.danmaku.bili`), 也可以粘贴应用商店链接 (`…details?id=包名`), 或在规则页"从已安装应用中选择".
- 接管 DNS 时, 拦截的查询回 NXDOMAIN (相当于桌面版的 403); 拦截记录里的应用按连接查出, 结果缓存 30 秒. 放行的查询转发给当前 Wi-Fi / 移动网络的 DNS.
- **有网站过滤时全部流量进 VPN** (不再只接管 DNS), 并丢掉会绕过明文 DNS 过滤的加密 DNS / QUIC: DoT (853 端口)、QUIC / DoH3 (UDP 443)、写死连公共 DoH 解析器 (443) 的连接 —— 逼应用回到明文 DNS (由 VPN 过滤). 否则社交平台用自带的加密 DNS 直接解析, 屏蔽不干净 (允许的站点改走 TCP, 照常可用).
- 计划变化时 (联网 / 断网, 名单生效, 切换方式) 先建好新的 VPN 再关旧的, 切换过程中不留空档.
  例外: 在"只接管 DNS"和"流量全部进 VPN"之间切换时 (例如 Adapter 下联网 ↔ 断网), 先关旧的再建新的 ——
  原地改路由在部分系统上不生效, 会出现"断网方式是 Adapter, 离线时却仍能上网".
- 每隔"断网复查间隔"检查一次 VPN 是否还在, 不在就重新打开.
- **被别的 VPN 应用顶掉时**: Android 同一时间只允许一个 VPN, 打开别的 VPN 应用会让 OIT 的 VPN 停下 (同时发一条通知).
  之后每次回到 OIT (从后台切回来, 点通知, 重新打开) 都会重新申请 VPN 权限并重新建立; Android 会弹出系统的确认窗口.
- **第一次打开**: 先只显示欢迎窗口; 关掉它之后把需要的权限依次都问一遍, 一次只弹一个系统窗口 / 设置页
  (同时弹两个系统窗口时, 在部分手机上会卡住整个界面). 已经有的跳过, 在设置页里不给也照样问下一项:
  通知 → VPN → 不受电池优化限制 → 精确闹钟 (Android 12 起) → 使用情况访问 → 显示在其他应用上层 → 安装未知应用 →
  手机厂商的 自启动 / 后台运行 设置页 (有这一页的手机才打开, 同时提示允许). 问过的记在数据目录 (`permissions_asked`), 重置后会再问一遍;
  从旧版本升级上来的, 升级后第一次打开时也会问一遍. 之后每次打开只补问通知 / VPN / 电池优化 (同前).
- 全屏蔽按 DNS 拦截: 直接用 IP 地址或自带加密 DNS 的应用拦不住 (同下面"按 DNS 过滤的限制"); 换来的是局域网照常可用, 可以设备同步.
- **断网自检** (白名单模式离线, 流量全部进 VPN 时): OIT 自己也在 VPN 里, 建好 VPN 后 (以及每次复查时) 直接连一下公共 DNS 的 53 端口, 应该连不上.
  连上了说明系统没有按 VPN 的路由走: 自动关掉重建一次; 还不行就在页面顶部显示"断网未生效"和"重新建立 VPN"按钮.
  设置 → 联网 的 VPN 一栏显示当前 VPN 在做什么 (全屏蔽 / 全部断网 / 按名单过滤 DNS / 全部放行) 和最近一次出错的原因.
- 按 DNS 过滤的限制: 直接用 IP 地址或自带加密 DNS 的应用不受网站名单限制; 已经建立的连接不会被切断.
  系统设置里的"私人 DNS"设成指定服务器时会绕过 OIT, 请设为"关闭"或"自动".
- 4.5 的连接处理 (403 页面, 每秒复查已建立的连接, 上游代理) 在 Android 上没有对应; 拦截计数 (8.6) 只统计接管 DNS 时的查询.
- 合约的网络禁令 (乐理之灾 / 无言为真 / 禁游令 / 低帧的诅咒) 会让 VPN 另外屏蔽这些应用的网络, 见 18.6.
- UP 主名单 (4.8) 手机上没有对应: VPN 只看得到域名, 读不到浏览器的页面. bilibili.com 在黑名单里就整个拦, 在白名单里就整个放行; 手机的规则页不显示 UP 主名单.
- 4.7 (关掉前台窗口) 在 Android 上换成**锁定应用**, 见 14.6.

### 14.3 关闭程序 (对应 2.7)

- Android 上没有"关闭程序": 返回桌面或从最近任务里划掉都不影响, 前台服务和 VPN 照常运行.
- 应用被强行停止时 VPN 随之关闭, 网络会恢复, 做不到桌面版的 fail-closed.
  可以在系统 VPN 设置里把 OIT 设为"始终开启的 VPN", 系统会自动把它重新拉起. **不要**打开"屏蔽未使用 VPN 的连接", 否则联网时也上不了网.
- 进程被系统回收后重新启动, 按第 3.3 节先断网, 再接着关闭前的申请 / 联网 (2.8).

### 14.4 计时器

- 休息倒计时也写进 `timer_state.json`: 进程被系统回收后重新打开, 休息照常倒计时 (已经走完的就按走完的时刻记下). 专注的恢复同 6.7.
- 休息倒计时按真实时间走, 设备睡眠时也在计时.
- 行为模式 (第 21 节) 和外出在手机上一样: Timer 页有"🚪 外出", 记录 / 整点记录 / 联网额度 / 休息奖励都和电脑相同, 外出记录通过设备同步共用.

### 14.5 提醒

- 只能手动关闭的提醒 (休息结束后迟迟不开始, "还在吗", 借得太多, 配置期结束 …) 同时显示为对话框和一条通知.
  点通知上的按钮和点对话框上的按钮一样; **划掉通知**等于点 ✕.
- 其他提示在 OIT 打开时显示在页面底部, 在后台时发一条普通通知.
- 整点提示音: 内置三音提示音, 或用系统文件选择器选一个音频文件 (放不出来时退回内置). 整点时同时发一条"填写上一小时"的通知, 点它打开 Hour Log 页.

### 14.6 窗口 → 应用 (对应 12, 8.3)

- **手机上没有后台应用数检测** (电脑上有任务栏窗口数上限, 第 12 节; 手机上曾经有"后台应用数检测"和"后台应用数上限"两项设置, 1.0.269 删除):
  Android 不允许普通应用知道别的应用还开不开着 (读多任务界面要电脑 adb 给 OIT 授予特权权限, 很多用户做不到; 不授予时只能数"刚用过的", 和多任务里实际开着的对不上), 数出来的不准, 所以手机上**不数后台应用**, 也没有这两项设置, 不再申请 DUMP 权限.
  合约的**通道阻塞** (18.3) 本来就是各设备看自己的: 电脑照常按窗口数检查, 手机上这个词条**不检查**.
- 窗口使用时间统计变为**应用使用时间统计**, 见 8.3.
- **锁定应用** (对应 4.7): Android 不允许普通应用关掉别的应用, 应用名单改为锁定.
  - 每 **1 秒**看一次前台应用 (使用情况访问权限):
    - 黑名单模式: 应用在应用黑名单里 → 锁定;
    - 白名单模式: 应用不在应用白名单里 → 锁定. 系统自带的应用不锁 (相机, 输入法, 系统更新等).
    - 同 4.7: 只在专注 / 空闲时锁, 休息中全部放行; 和是不是在联网会话中无关.
  - 锁定 = 盖上一层"🔒 已锁定"挡住整个屏幕, 并回到桌面; 离开那个应用后盖层自动撤掉. 盖层上有"回到桌面"按钮.
    需要允许 OIT "显示在其他应用上层"; 没有这个权限时只弹提示, 挡不住. 缺权限时 Rules 页名单下方标出, 带去授予的按钮.
  - 永远不锁: 桌面, 系统界面, 锁屏, 设置, 电话 / 紧急呼叫, 权限确认, 安装器, OIT 自己, 以及查不到的应用.
  - 锁定时弹出提示 (同一个应用 5 秒内只提示一次), 记进拦截记录 (显示为 `🔒`, 8.6) 和 `window_guard.log`.
  - 两种断网方式下都生效. 全屏蔽时这是唯一起作用的名单: Rules 页只显示当前过滤名单模式的应用名单, 网站名单不显示.

### 14.7 AI 名单建议 (对应 5)

- 采集内容: 已安装的应用 (名称与包名, 最多 120 个), 回看天数内各应用的使用时长 (最多 25 个, 需要使用情况访问权限), 以及本次运行通过 OIT 查询过的域名和次数 (最多 50 个). Android 上读不到浏览器的访问记录.
- API Key 用 Android Keystore 加密保存, 只有本机上的 OIT 能解开; 换设备或重装后需要重新填写.
- 其余 (服务商, 只发往官方地址, 只走 https, 拒绝跳转, 抹掉回显的 Key, 1500 tokens, 90 秒) 同第 5 节.

### 14.8 其他

- **手机上所有页面都藏起状态栏** (从屏幕顶部下滑时临时出现), 做法和指令页 / 合约页一样; 切页, 回到前台, 窗口拿到焦点时都会再设一遍.
- **睡眠页** (都市之意主题): 正中指令页的图标, 下面的"醒来"只有蓝色的字, 没有按钮底色 (同电脑版); 其他主题是填充的"☀ 起床"按钮.
- 卸载: Reset 页的"卸载 OIT"先请绑定的设备清空数据并解除和本机的绑定 (同 9.1), 恢复网络, 删除全部数据, 再打开系统的卸载确认.
  直接在系统里卸载时来不及通知别的设备 (见 15.1).
- 界面字号, 语言同第 1.2 节, 选中就生效, 盖一层带进度条的加载页, 界面在它后面换好.
  **界面主题**在手机上要重启 OIT 才生效: 选中后弹窗"界面主题将在重启 OIT 后生效. 现在重启吗?", 点确定立即重启界面.
- **开机自启动**: 默认开启 —— 开机后系统发来开机广播, OIT 自己启动 (第一次打开时会带去手机厂商的"自启动"设置页, 见 14.2).
  厂商的"自启动"开关 OIT 查不到, 所以每次开机由系统启动成功时记下这是第几次开机 (`BOOT_COUNT`):
  这次开机是 OIT 自己启动的才算开着开机自启动; 被厂商拦住 / 用户关掉了 (这次开机后是自己手动打开的), 或者装好后还没重启过, 都算没开.
  开着开机自启动是其他设备把本机算作"关机"而不是"离线"的前提 (15.4).
