# 21. 行为模式 (设置 → 日常)

[← 返回目录](../../MECHANICS.md)

设置 → 日常 最上面的**行为模式**决定外出怎么记录. Timer 页第二行的外出按钮三种模式都有, 只是名字和规则不同:

| 行为模式 | 外出按钮 | 效果 |
| --- | --- | --- |
| **封闭式管理** | 🚪 上学 | 下面的记录 / 整点记录 (上学) / 联网额度 / 休息奖励都生效 |
| **工作** | 🚪 工作 | 和封闭式管理完全一样, 整点记录叫「工作」 |
| **自由学习** | 🚪 外出 | 只是一个标记, 不记录, 不限制 (21.6); 整点记录叫「外出」 |

- **第一次选择**: 第一次打开软件时 (还没有 `app_settings.json`) 会得到**一次免等待**, 在 设置 → 日常 选好模式立即生效.
  之后修改要等 **168 小时 (7 天)**, 配置期也不提前生效 (和别的设置不一样). 等待期里可以取消.
- 选好以后行为模式随设置同步到其他设备; 每台设备各自记下"从什么时候开始用这个模式" (`mode_since`, 不同步),
  整点记录只改这个时刻之后的小时, 不会把以前的记录翻出来改掉.
- 整点记录的自动填充文字是固定的 (见 21.3), 不在设置里.

### 21.1 外出

- 行为模式是封闭式管理 / 工作时, Timer 页第二行的外出按钮叫 **"🚪 上学" / "🚪 工作"**. 点开填持续多少小时 (整数, 1 ~ 168), 可以跨天.
  只在准备状态 (没有在专注 / 休息), 并且不在合约里时能开始; 同时只能有一次外出.
- 外出中 Timer 页的大字变成外出的剩余时间, 下面写已经记录了多少小时; 主按钮和副按钮不可用,
  外出按钮变成 **"🚪 结束外出"**. 点它确认后提前结束 (已经过去的部分照常记录).
- 到时间自动结束. 程序关着的时候到时间也一样: 下次打开时按原定的结束时刻补上, 并补发休息时间.
- 外出中不能开始专注 / 休息, 不会弹"该开始下一轮了"的提醒, 也不能开始合约; 合约进行中不能开始外出
  (填外出时长的窗口开着时开始了合约, 确认时也会被拦下). 两台设备同步时撞上的见 21.5.
- 结束外出时弹提示, 写明记录了多久.

### 21.2 记录规则

**不写** `study_log.json` / `focus_log.json`; 今日学习时长, Calendar, Statistics 的专注计时在显示时直接把外出记录叠加上去
(所以不会因为设备同步重复计). 对每一天 (按自然日, 跨天分开算):

- **记录小时数** = 这一天外出经过的秒数 ÷ 3600 **向下取整**, 每天最多 **10 小时** (不足 1 小时的部分不计). (统计 / 专注计时 / 休息奖励和"已经记录了多少小时"都用它)
- **专注计时**: 按被记录的每个小时填充: **7:00 ~ 睡觉时间** (第 19 节, 按那天是星期几; 默认 23:00) 之内的部分按 **80% 专注 / 20% 休息**
  (例如 10:00 ~ 14:00 就是 3.2 h 专注 + 0.8 h 休息); 睡觉时间 ~ 第二天 7:00 的部分只算休息.
  - 睡觉时间不在整点也一样: 例如 23:30 睡, 23:00 ~ 23:30 这半小时照样按 80% / 20% 填 (24 min 专注 + 6 min 休息), 23:30 以后只算休息.
  - 睡觉时间在凌晨 (例如 00:30) 时, 填充一直到第二天 00:30; 最晚到第二天 7:00.
  - 用的是睡觉时间当前生效的值 (改了要等 48 小时, 第 1 节); 已经记下的外出显示时也按当前的值重新算.
  - **10 小时的名额先给白天**: 一天里被记录的小时数先按时间顺序填 7:00 ~ 睡觉时间之内的部分, 填满了 (或白天的部分用完了) 还有剩下的才填夜里.
    夜里的小时不占白天的名额. 例: 周日 18:00 出门住校, 周五 18:00 回来 (一次 120 小时): 周日记 6 小时 (18:00 ~ 23:00 的 5 小时 → 4 h 专注, 再加夜里 1 小时休息),
    周一到周五每天记 10 小时, 都填在 7:00 ~ 17:00 → 每天 8 h 专注.
  每天最多画 10 小时; 超过 10 小时的部分不再记录.
- 因此学习时长 = 7:00 ~ 睡觉时间内被记下的专注部分; 统计 / 日历会自动包含它, 成就的"一天学了多少"也算.
- **休息奖励**: 外出结束后, **被记录的小时数 × 6 分钟**, 最多 **3 小时**, 存进积攒的休息时间.
  每次外出只发一次; 由**开始这次外出的设备**发 (和计时器的记录只记一次一样), 它没在时其他设备不重复发, 等它下次打开再发.
- 进行中的外出也会实时叠加到今日 / 统计里 (记到此刻为止); 结束后按实际结束时刻定下来.

### 21.3 整点记录

- 这一小时和外出有重叠 → 按这次外出的种类, **上学 / 工作 / 外出各有自己独立的自动填充内容**:
  封闭式管理的外出 → **「上学」**, 工作的外出 → **「工作」**, 自由学习的外出 → **「外出」** (记在外出里的种类, 以后换了行为模式也不变);
- **封闭式管理 / 工作 (1.0.392)**: 没有被填充专注与休息的小时一律自动填成 **「睡眠」**: 外出之外的时间, 以及外出里没有被 8:2 填充到的小时 (超出每天 10 小时名额的部分); 有被填充专注 / 休息的外出小时才填「上学」/「工作」. 自由学习里其他时间照常用超时自动记录内容 (Distracted).
  (原来这些小时填的是「休息」, 现在 REST_TEXT 不再用于整点记录.)
- 这几个文字是固定的, **不能改**: 整点记录页里内容是 睡眠 / 上学 / 工作 / 外出 / 休息 这种自动填充的格子**锁住 (🔒) 不能编辑**;
  只有「超时自动记录内容」(默认 Distracted) 自动填的格子可以改, 自己填的格子也照常能改. 英文界面写 School / Work / Out / Break.
- 只是超时自动填充的内容; 自己填写的小时照常以自己的为准.
- 合约的"整点记录超时"判定仍然把这些自动内容当作没填 (和普通的 `Sleeping` 一样).
- 关闭程序期间错过的整点记录, 在下次打开时补记, 同样按上面的规则.

### 21.4 联网额度与冷静期

- **当天有外出** (正在进行或已经结束, 并且行为模式是封闭式管理 / 工作) 的日子, **只能用今天总额度的 20%**:
  总额度 = 每日额度 × 星期倍率 + 紧急借贷借到的 + 合约奖励的, 这些加起来再取 20% (每日额度 2 小时 → 24 分钟; 再借 1 小时 → 36 分钟).
  借贷和合约奖励也一样只有 20% 能用 (不是加在 20% 的额度上面). 这一天结束之前都按 20% 算, 外出结束后不会恢复; 已经用掉的部分照常算.
- 昨天借贷留下的欠款照常从能用的部分里扣. 借明天的额度时按明天的每日额度算 (不打折); 明天有外出的话, 明天照样只能用明天总额度的 20%.
- **正在外出时**提交普通申请, 联网冷静期 **×0.3** (默认 5 分钟 → 1.5 分钟); 和休息中 / 合约的冷静期倍率相乘.
- Network 页会写出"外出: 今天只能用总额度的 20% (总额度 … → 能用 …)"和"外出中: 联网冷静期 ×0.3"; "今日已用 x / y" 里的 y 是能用的那 20%.

### 21.5 多台设备

- 外出记录和它的开始 / 结束时刻一起同步 (见 15.2): 在一台设备上开始外出, 其他设备也显示外出中, 同样不能专注.
- 每一次外出单独比较, 后改的覆盖先改的; 已经结束 / 已经发过休息时间的外出不会被一份旧记录复活.
- 两台设备同时开始了不同的外出时, 只保留**最晚开始**的那次, 早的那次在后者开始时结束.
- 合约和外出不能同时进行. 万一同步时撞上了 (一台设备在合约中, 另一台还没收到合约就开始了外出, 或者反过来), **外出让路**:
  外出在合约开始的时刻结束, 合约开始之前的部分照常记录 / 发休息时间; 比合约晚开始的外出整次作废 (不记录, 不算"当天有外出"). 弹提示"合约进行中, 外出已结束.".
- `mode_since` (整点记录从什么时候开始用这个模式) 不同步, 每台设备各自记; 两个自动记录文本本身按设置同步.
- 行为模式本身是设置, 按设置的同步规则走 (后改的覆盖先改的); 第一次打开时给的那次免等待只在本机.

### 21.6 自由学习的外出

自由学习里也有外出 (按钮叫"🚪 外出"), 但它不是"记录出来的外出", 只是告诉 OIT "这台设备带出门了":

- **什么都不限制**: 外出期间可以正常开始专注 / 休息 / 睡眠 / 合约 (也可以在专注 / 休息 / 合约进行中开始外出); 不画进学习时长,
  不叠加到统计和日历, 不改联网额度和冷静期, 结束时不发休息时间. 整点记录里外出的小时自动填「外出」.
- **其他设备离线不算**: 外出期间 (从开始到结束) 其他设备的离线**不记为空闲** (专注照常计入学习时长, 专注计时条形图也不画空白),
  不触发"绑定的设备离线累计超过 5 分钟自动结束专注", 不让合约因"设备离线"失败, 不响"X 离线了", 不请它重新启动 OIT (15.3) (封闭式管理 / 工作的外出也一样, 见 8.4); Timer 页写"🚪 外出中: 其他设备离线不影响专注和合约.".
  这样没有连接上其他设备也能正常计算专注 / 开始合约. 外出结束后离线设备照常算离线 (合约的离线 15 分钟从外出结束的时刻起算).
- **回来后的同步优先权**: 外出结束后, 外出的设备**第一次同步上**时 (最多等 48 小时), 它在外出期间改过的东西有优先权 ——
  - 计时器此刻的状态 (专注 / 休息 / 空闲) 和与外出重叠的那些小时的整点记录, 别的设备在外出期间 (它结束之前) 改的让位给它,
    不再"后改的覆盖先改的"; 外出结束之后别的设备才改的照旧按时间比;
  - 别的设备自己记下的、和它在外出期间重叠的专注计时记录 (专注 / 休息 / 空闲) **全部让位给它**: 重叠的部分删掉, 删掉的专注从学习时长里扣掉
    (不看 15.5 的 休息 > 专注 > 空闲), 弹提示写明去掉了多少;
  - 状态里的 `away: [开始, 结束]` 就是告诉别人"我刚回来", 同步上以后消失.
- 外出的记录 (`mode` 字段是 `free`) 和别的外出一样随设备同步 (15.2 的行为模式一行); 同时只能有一次外出.
