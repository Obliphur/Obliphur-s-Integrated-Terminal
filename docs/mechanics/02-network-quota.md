# 2. 联网额度与申请 (Network 页)

[← 返回目录](../../MECHANICS.md)

### 2.1 每日额度

- 每天的额度 = 每日联网额度 (默认 **2 小时**) × 当天的星期倍率 (默认 ×1) + 今天通过紧急借贷借到的额度.
  例如每日额度 2 小时, 周六倍率 ×1.5, 周六的额度就是 3 小时; 倍率 ×0 表示当天没有额度.
- **行为模式的外出** (第 21 节): 行为模式是封闭式管理 / 工作, 且当天有外出的日子, **只能用今天总额度的 20%**
  (总额度 = 每日额度 × 星期倍率 + 今天借到的 + 今天合约奖励的; 例如总额度 2 小时 → 只能用 24 分钟; 借了 1 小时, 总额度 3 小时 → 能用 36 分钟).
  已经用掉的额度照常算 (外出前已经用掉的超过 20% 时, 今天就没有剩余了); 昨天借贷留下的欠款照常从能用的部分里扣. 这一天结束之前都按 20% 算 (外出结束后也不会恢复).
- 星期按程序记录的"今天"计算, 零点换日时随之切换到新一天的倍率. 倍率在当天中途生效 (例如配置期内修改) 时, 当天的额度立刻按新倍率计算, 已消耗的部分不变.
- 倍率不是 ×1 时, Network 页会显示"今天的联网倍率", 以及每日额度和今天实际额度.
- 今日剩余 = 今日额度 - 今天已消耗 - 昨天借贷留下的欠款.
- 每天零点重置: 已消耗清零, 借到的额度清零, 昨天借贷要还的部分变成今天的欠款. 零点一过立刻生效 (开发者模式下也照常跨日).
  绑定的设备里还停在昨天的 (还没跨日 / 还没同步过来) 按它跨日后的样子算: 它昨天借的变成今天的欠款, 其余不算, 不用等它同步.
- 剩余额度不足 1 分钟时, 不能再提交普通申请.
- Network 页的状态后面写着当前的断网方式 (例如 "离线 · 代理-全屏蔽 (Proxy block-all)"), 两端都是.

### 2.2 普通申请

1. 填写分钟数 (整数, 至少 1) 和理由 (必填). 一次申请有多个理由时用 `/` 连接, 如 `查资料/下载课件`.
2. 提交后进入联网冷静期 (默认 **5 分钟**). 这期间可以取消, 也可以改为快速访问.
   **正在外出时** (第 21 节), 冷静期 ×**0.3** (默认 5 分钟 → 1.5 分钟); 和休息中 / 合约的倍率相乘.
3. 冷静期结束后自动联网. 实际给出的时长 = min(申请时长, 联网那一刻的剩余额度).
   冷静期内**不预留额度**: 如果这期间额度被别的方式用掉, 实际给出的时长会变短.
4. 联网期间按实际经过的时间扣额度 (×1). 时间到了自动断网.
5. 可以随时"结束本次会话". 没用完的时间不扣额度.
6. 申请时长超过剩余额度时会被拒绝; 如果还能借贷, 提示里会给出最多能借多少.

### 2.3 快速访问 ⚡

- 跳过冷静期, 提交后约 1 秒内联网 (需要确认一次).
- 额度按 **×2** 消耗: 联网 10 分钟, 扣 20 分钟额度.
- 最多能快速访问的时长 = 今日剩余 ÷ 2.
- 冷静期中的普通申请可以"改为快速访问", 同样按 ×2 计费, 并立即联网.

### 2.4 紧急借贷 💳

- 借贷**本身不联网**, 只是给今天加额度. 借到的额度仍要通过普通申请或快速访问来使用.
- 今天额度 +X, 明天额度 -X × **2**.
- 最多能借的量 = 明天剩余额度 ÷ 2. 每日额度为 2 小时时, 一天最多借 1 小时.
- "明天的额度"按明天是星期几、用明天的倍率计算. 例如明天倍率 ×0, 今天就借不到任何额度.
- 借到的额度今天用不完也不退.
- 欠款只扣一天: 明天还清后不会继续滚到后天.
- 借贷之后关掉程序也要还: 欠款记到借贷之后**第一次打开程序的那一天**, 中间隔了几天也一样.
- **借得太多时的提醒**: 某次借贷让明天已被借掉的部分 (明天要扣的总量) 第一次达到明天额度的 **一半**时, 弹出一个只能手动关闭的提醒:
  建议到 设置 → 计时器 里调高"休息时间倍率", 并告知"每日联网额度"的下一次修改免等待. 每天最多触发一次 (换日后明天的借贷记录重新开始).

### 2.5 休息中申请

- 计时器处于休息倒计时时提交普通申请, 并且申请时长 ≤ 剩余休息时间, 联网冷静期 ×**0.4** (默认 5 分钟 → 2 分钟).
- 申请时长超过剩余休息时间时, 冷静期不打折.
- 联网期间不能暂停休息 (按钮会变灰).

### 2.6 计时细节

- 联网计时大约每秒走一步, 每一步最多计入 **30 秒**. 电脑睡眠或程序卡住后恢复时, 不会一次扣掉一大段.
- 联网会话跨过零点时继续进行, 零点之后的消耗计入新的一天.
- 已消耗的额度每 5 秒写入一次磁盘, 会话开始, 结束和借贷时也会立刻写入.

### 2.7 关闭程序时

- 排队中的申请和进行中的联网**留着**, 重新打开时接着用 (2.8). 关着的这段时间网络是断的 (见下), 也不扣额度.
- 已经消耗的额度保留, 当天重新打开时继续累计.
- 关闭时程序会断网 (fail-closed), 不会留下"没有限制"的状态.
  - Adapter 模式: 物理网卡保持禁用.
  - Proxy 模式: 系统代理仍然指向本程序, 但程序已经退出, 所以遵守系统代理的程序都连不上网.
- 需要立即恢复网络时, 可以使用 Reset 页 (第 9 节): 重置后按默认设置运行, 什么都不拦.
  程序打不开, 或者不想再用时, 使用卸载程序 (第 9.1 节).

### 2.8 联网状态: 关掉再打开时接着用, 随设备同步

- **联网状态** = 等待中的申请 (理由, 分钟数, 冷静期到几点, 是不是快速访问) / 进行中的联网 (到几点结束, 计费倍率). 都按墙上时间记, 存在 `net_state.json`.
- **关掉程序再打开** (电脑关闭 OIT, 手机进程被系统回收): 申请还在等就接着等 (冷静期按原来的时刻, 关着时已经到了就马上开始联网);
  联网还没到原来的结束时刻就接着联网到那个时刻, 已经过了就是离线.
- **设备同步** (第 15 节): 联网状态和计时器状态一样, 哪台设备最后改动就以哪台为准 —— 在一台设备上申请, 别的设备上也显示申请中;
  冷静期到了各设备一起联网, 到同一个时刻结束; 在任何一台上提前结束 / 取消申请, 别的设备也跟着断网 / 取消 (提示"联网已在其他设备上结束").
  - 额度是所有设备共用的 (2.1), 同一次联网只扣一次: 由**发起的设备**按倍率扣; 它 2 分钟没同步 (不在线) 时由本机扣.
  - Adapter 断网方式 (15.5) 下不同步, 照旧各管各的.
