# 19. 睡觉时间 (设置 → 日常)

[← 返回目录](../../MECHANICS.md)

- 设置 → 日常 里可以改周一到周日各自的**开始睡觉时间**, 默认都是 **23:00**. 和别的数值项一样是 48 小时生效,
  按 `HH:MM` 填写 (也认 `2300` / `23`). 这一页还放行为模式 (第 21 节), 睡觉时间按星期排成 7 行, 上面有"🌙 睡觉时间"标题.
- "最近一次睡觉时间" 按那一天是星期几取对应的那条, 跨零点: 凌晨还没睡时算的是昨天那次
  (凌晨 1 点的最近一次睡觉时间是昨晚 23:00).
- **暂停休息时的提示**: 最近一次睡觉时间之后 **3 小时**内, 非合约期间第一次**暂停休息**
  (按"⏸ 暂停休息", 或休息中按"▶ 开始专注"), 弹出一次 Obliphur 的提示
  ("你好,主管…到了应该睡觉的时间了…晚安"), 这次休息的**暂停结转比例 +5%** (默认 ×0.7 → ×0.735).
  - 同一个睡觉窗口只弹一次, 弹过就写进数据目录的 `daily.json` (关掉程序再打开也算弹过).
  - 自然走完的休息没有结转, 不算这一次 (不弹也不加成); 合约中暂停不算 (18.1); 关闭程序时的自动暂停不算.
  - "完成合约后的第一次休息" 本来就按 `1 - (1 - x) / 2` 算 (18.2), 再加 5% 就是乘在它上面.
- **合约开始前的确认**: 合约的结束时间 (现在 + 时长, 见 18.1) 晚于"这次要睡的时间"时, 当天第一次按"开始行动"
  先弹一次确认: "如果正常完成行动 会延迟你的睡眠至少 N min 你真的要开始吗?", 取消就不开始.
  - N = 合约结束时间比"这次要睡的时间"晚的分钟数, 向上取整.
  - "这次要睡的时间": 还在睡觉后的 3 小时窗口里 → 最近那次 (已经晚了); 已经过了窗口 → 下一次
    (白天 / 傍晚开始合约时, 比的就是今晚). 例: 21:00 开始 3 小时的合约 → 结束 00:00, 比今晚 23:00 晚 60 min.
  - 当天只弹一次; 弹过就算 (这次结束了, 再换更长的一组词条也不弹).
- 两个提示的标记各自存在 `daily.json` 里, **只记日期, 不同步**: 每台设备各自弹 (和 15.2 里规则页的名单一样只在本机).
- 这两个提示只是提醒, 不影响合约和休息本身的规则.
