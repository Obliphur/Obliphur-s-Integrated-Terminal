# 7. 整点记录 (Hour Log 页)

[← 返回目录](../../MECHANICS.md)

- 每到整点 (约整点 0.1 秒后) 播放提示音, 提醒填写**上一小时**做了什么. 绑定了其他设备时**只在焦点设备上响** (最后有人操作的那台, 15.2), 其他设备只标出待填写.
  侧栏的 Hour Log 按钮出现 `●`, 直到填写完成, 或者超过补填时限.
- 每一行左边写的是这一小时的**起点**. 最上面的 23:00 行对应昨天 23:00 ~ 24:00.
- 一小时做了多项活动时用 `/` 连接, 如 `学习/吃饭` (全角 `／` 也可以识别). 统计时怎样算见 8.2.
- 已经结束的小时可以随时修改, 包括已被自动记录的小时. 还没结束的小时不能填写.
- **自动记录**: 一小时结束后超过补填时限 (默认 **1 小时**) 仍未填写, 自动记下:
  睡眠 (23 节) 占了这一小时 **30 分钟以上**的记成 **睡眠 / Sleeping**; 其余的记成"超时自动记录内容" (默认 **分心 / Distracted**).
  行为模式的外出 / 其他时间 (21 节) 有自己的自动内容, 优先. 起床时, 睡眠期间已经被记成非睡眠自动内容的小时改成"睡眠".
  **默认的自动内容跟随界面语言** (睡眠 / Sleeping, 分心 / Distracted, 发呆 / Idle, 休息 / Break 是同一项): 切换语言时整点记录里这些内容自动换成新语言并合并
  (统计里总是合成一项; 设备同步时别的设备写的另一种语言也合并, 自动内容照样让位给自己填写的); 自己填写的别的文字不动.
  程序关闭期间的小时, 在下次启动时补记, 但最早只补到昨天 23:00.
  **行为模式** (第 21 节) 是封闭式管理 / 工作时, 不用这一项: 这段时间里外出的小时填「上学」/「工作」, 没有被填充专注与休息的小时填「睡眠」 (见 21.3;
  行为模式生效之前的小时不受影响). 合约的整点记录判定照常把这些自动内容算作没填.
- **提示音**: 默认播放内置三音提示音 (784 / 988 / 1319 Hz), 也可以指定本地 .wav 或 .mp3 文件. 文件不存在或放不出来时退回内置提示音.
  设置 → 整点记录 里"▶ 试听"放的是下拉框里此刻选中的那个 (还没提交也可以试听). 自选的文件在界面上只显示文件名, 不显示路径.
  .mp3 用 Windows 自带的 MCI 播放, 不需要额外安装. 提示音很长时照样放完, 但"填写上一小时"的提示最多等 10 秒就出现.
- **关闭整点记录**后: 不响铃, 不自动记录, 也不能填写. 开关在 Settings 页, 遵守设置冷静期.
- **合约** (18.4): 合约中超过补填时限还没填写算一次违反; 记录封锁 / 细化规范两个词条另外改变整点记录.
