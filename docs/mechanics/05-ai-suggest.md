# 5. AI 名单建议 (Rules 页)

[← 返回目录](../../MECHANICS.md)

- 流程: 同意采集 → 采集本机信息 → 预览 → 确认发送 → 勾选建议 → 写入名单.
  模型给出的永远只是候选, 不会自动写入名单. 写入时照常遵守第 4.4 节的冷静期.
- 采集内容: 已安装的应用 (开始菜单和注册表, 最多 120 个), 以及浏览器访问记录中的**域名和访问次数** (不读具体网址, 页面标题或搜索词).
  支持 Chrome / Edge / Firefox / Brave. 回看天数可选 30 / 90 / 365 天, 默认 90 天. 每个浏览器最多取 25 个域名, 合计最多 50 个.
- 采集到的内容只在内存里, 不写文件.
- **API 配置**: 最多 **10 份命名的配置** (1.0.444), 每份各自有服务商预设 / 模型类型 / Base URL / 型号 / API Key, 互相独立; 在 设置 → 沟通 → API 里新建 / 改名 / 删除, 并指定哪一份是**默认配置** (规则页的 AI 建议等不分对象的功能用它). **沟通页**右上角的下拉框不再选模型, 而是**选这份 AI 用哪份配置** (每个 AI 各记各的, 存在 `ai_config.json` 的 `assign`; 没选过就用默认配置). API Key 保存在数据目录的 `ai_config.json`.
- **API 设置随绑定同步** (1.0.416; 1.0.444 起是多份配置): 默认配置, 配置列表 / 名字 / 每一份的模型类型 / Base URL / 型号 / API Key, 以及每个 AI 选的那份都随设备同步 (文档 `ai`, 每一项单独比较, 后改的覆盖先改的). Key 在同步通道里由绑定时的配对密钥封着传 (和聊天记录同一条通道), 对方设备收到后用**本机的** DPAPI (手机是 Keystore) 重新加密保存; 同步状态文件里只有 Key 的哈希. **空值不覆盖已有的值**: 没配置过 API 的设备不会把另一台的型号 / Key 冲掉, 清空 Key 只在本机生效. 没有绑定设备时 API 设置仍然只在本机.
- **API Key 的保护**:
  - 存盘前用 Windows 自带的 DPAPI 加密, 只有当前 Windows 账户能解开; 文件被拷到别的电脑或别的账户下也读不出 (那时 Key 显示为空, 需要重新填).
  - 旧版本以明文保存的 Key, 程序下次打开 AI 设置时自动改存为加密.
  - 预设服务商 (Claude / ChatGPT / Gemini / DeepSeek) 的 Key 只会发往它们的官方地址 (`api.anthropic.com` / `api.openai.com` / `generativelanguage.googleapis.com` / `api.deepseek.com`). 要用中转等其他地址, 请选"自定义供应商".
  - **自定义供应商必须明确选『模型类型』** (Claude / ChatGPT / Gemini / DeepSeek / 其他): Base URL 看不出是哪一家, 类型决定接口协议 (anthropic / openai / 原生 gemini) 和提示缓存的策略 (`ai_assist.cache_plan`). 只填模型名不算, 不按名字猜; 老配置按存的协议 / DeepSeek 官方地址认一次, 其余算"其他".
  - "其他" = 中转 / 本地模型: 走 OpenAI 兼容协议, 不假设服务商有提示缓存 (照旧带 thinking 关闭, 不认就 400 后去掉重试).
  - 只走 https (本机模型可用 http://localhost). 服务商要求跳转时一律拒绝, 不把 Key 带到别的地址.
  - 服务商的报错里如果回显了 Key, 显示前会抹成 `***`. Key 不写进任何日志.
- 每次请求最多返回 1500 tokens, 超时 90 秒. 每类建议最多 30 条; 白名单模式下, 记录以外的推荐网站最多 12 个.
- 黑名单模式下, 模型不给理由, 只给条目.
- AI 请求同样走系统代理, 但**当前服务商 Base URL 的主机是过滤代理的例外**: 白名单 / 黑名单 / 代理-全屏蔽都不拦它, 聊天和 AI 名单建议因此能正常连接; 合约的网络禁令 (18.3) 仍然优先.
