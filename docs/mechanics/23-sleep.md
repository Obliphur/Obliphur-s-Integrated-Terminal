# 23. 睡眠 (Timer 页)

[← 返回目录](../../MECHANICS.md)

睡眠是**单独的一种时间**, 不同于专注 / 休息 / 空闲: 记进专注计时记录 (`focus_log.json` 里 `k = "sleep"`, 同样保留最近 7 天, 各设备的合在一起算), 在 Calendar 里单独看 (8.2).

- Timer 页的按钮行里有 **😴 睡眠**: 只有**空闲**时能按 (在专注 / 休息中, 外出中 (21 节), 合约中 (第 18 节) 灰掉 / 提示原因).
- 睡眠中: 整个窗口 (电脑) / 整个界面 (手机) 被盖住, **空白背景, 正中只有一个"☀ 起床"**; 用户碰不到 OIT 的其他任何功能 (侧边栏 / 菜单 / 返回键都不起作用, 键盘 Tab 也跳不出去).
  **程序照常运行**: 断网 / VPN 防修改 (3.2.2, 14.2), 设备同步, 开机自启动, 联网计时, 到期的设置改动, 整点记录的自动填写都不受影响.
  没人在用所以不提醒: "该开始下一轮了" 不弹, 整点记录的提示音不响 (只标出待填写).
- **起床**: 这段睡眠 (开始 ~ 此刻) 记下来, 回到空闲 (休息结束后迟迟不开始的提醒从此刻算); 睡眠期间已经自动记成"分心"的小时改成"睡眠" (8.2).
- 睡眠中关掉程序再打开 (电脑重启, 手机进程被系统回收) **接着睡**, 关着的这段也算睡眠.
- **设备同步** (15.2): 睡眠是计时器状态的一种 ("空闲 / 专注 / 休息 / 睡眠"), 后改的覆盖先改的 —— 在一台设备上点睡眠, 另一台也盖上"起床"页; 任何一台点起床两边都醒
  (这段睡眠由点起床的设备记, 随账同步给另一台). 睡眠中另一台设备开始了专注 / 休息 / 外出 / 合约, 这台也跟着醒 (每 5 秒检查一次).
- 自动记录整点记录时睡眠占 30 分钟以上的小时记成"睡眠" (8.2).
